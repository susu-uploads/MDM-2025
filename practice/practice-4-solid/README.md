# Практика 4 — SOLID

Доменная логика находится в файле `calculator.py`.
Точка входа консольного приложения находится в файле `main.py`.

## Запуск приложения

```bash
python3 main.py
```

После запуска введите одно выражение и нажмите Enter.

Пример:

- Ввод: `1+1`
- Вывод: `2`

Другие примеры выражений:

- `1+1`
- `5/0`
- `sqrt(-25)`
- `sqr(3)`

## Тесты

```bash
python3 -m unittest -v test_calculator.py
```

## Как соблюдены принципы SOLID

- **SRP**: отдельные классы отвечают за отдельные задачи:
  - `ExpressionParser` только парсит выражения;
  - `Calculator` только вычисляет;
  - `main.py` отвечает за консольный ввод/вывод, форматирование результата и человекочитаемые сообщения об ошибках;
  - классы операций (`AddOperation`, `SqrtOperation` и т.д.) реализуют только свою операцию.
- **OCP**: новые операции добавляются через новые классы и регистрацию в `OperationRegistry`, без изменения логики `Calculator`.
- **ISP**: интерфейсы разделены на `BinaryOperation` и `UnaryOperation`, операции не зависят от лишних методов.

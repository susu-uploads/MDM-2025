# Практика 7-4: Strategy (Python)

Реализован паттерн `Strategy` для формирования отчётов в приложении «Кинопрокат».

## Что реализовано

- `movie.py`: типы и сущность фильма (`MovieType`, `Movie`).
- `pricing.py`: тарифные политики расчёта (`PricePolicy` и конкретные реализации).
- `rental.py`: сущность аренды (`Rental`), делегирующая расчёт в `pricing.py`.
- `customer.py`: арендатор (`Customer`) и агрегирование итогов.
- `statements.py`: стратегия `Statement` и две реализации:
  - `TextStatement`
  - `HTMLStatement`
- `main.py`: консольное формирование отчета.
- `test_strategy.py`: unit-тесты.

## Диаграмма классов

```text
+------------------+   aggregates   +------------------+   has   +------------------+   typed by   +------------------+
|     Customer     | -------------> |      Rental      | ------> |      Movie       | -----------> |    MovieType     |
+------------------+                +------------------+         +------------------+              +------------------+
        |                                    |
        | uses strategy                      +------------+
        v                                                 |
+------------------+                +------------------+  |
|    Statement     | <------------- |  TextStatement   |  |
+------------------+    inherits    +------------------+  |
        ^                                                 |                                     
        | inherits                                        |
        |                                                 |
+------------------+                                      |
|  HTMLStatement   |                                      |
+------------------+                    delegates pricing |
                                                          v
+------------------------+   inherits   +-------------------+
|   RegularPricePolicy   | -----------> |                   |
+------------------------+              |                   |
+------------------------+   inherits   |                   |
| NewReleasePricePolicy  | -----------> |    PricePolicy    |
+------------------------+              |                   |
+------------------------+   inherits   |                   |
|  ChildrenPricePolicy   | -----------> |                   |
+------------------------+              +-------------------+
```

## Запуск приложения

```bash
python3 main.py
```

Формат ввода:
1. Первая строка: формат отчета (`text` или `html`).
2. Вторая строка: имя арендатора.
3. Далее строки аренды: `title;movie_type;days`
   `movie_type`: `regular`, `new_release`, `children`.
4. Пустая строка завершает ввод.

Пример ввода:

```text
text
Иван
Матрица;new_release;3
Терминатор;regular;1
История игрушек;children;4

```

Пример вывода:

```text
Учёт аренды для Иван
	Матрица	9
	Терминатор	2
	История игрушек	3
Сумма задолженности составляет 14
Сумма очков за активность составляет 4
```

## Запуск тестов

```bash
python3 -m unittest -v test_strategy.py
```

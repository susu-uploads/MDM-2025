# Практика 7-6: Singleton (Python)

Реализован паттерн `Singleton` с демонстрацией того, что у программы есть один объект и несколько ссылок на него.

## Что реализовано

- `singleton.py`: класс `Singleton` с ленивым созданием экземпляра.
- `main.py`: демонстрационный сценарий (аналог шагов из методички).
- `test_singleton.py`: unit-тесты на поведение singleton и сценарий запуска.

## Диаграмма классов

```text
+------------------+   uses get_instance()   +------------------+
|      Main        | -----------------------> |    Singleton     |
+------------------+                          +------------------+
         | ref A ---------------------------->|
         | ref B ---------------------------->|
      обе ссылки в Client указывают на один Singleton
```

## Запуск приложения

```bash
python3 main.py
```

Пример вывода:

```text
singleObject = True
singleObject = False
```

## Запуск тестов

```bash
python3 -m unittest -v test_singleton.py
```
